## Implementation Constraints

- Use one bounded-context module:
  `apps/order/src/app/modules/order/order.module.ts`.
- Follow the backend family pattern:
  `controllers/`, `services/`, `repositories/`, `tests/`.
- Entity class names are `Order`, `OrderItem`, `Session`, `Bill`,
  `ServiceRequest`, `OutboxEvent`.
- Do not use `OrderEntity` / `SessionEntity` class suffixes.
- Every Order table includes `tenant_id`.
- Do not add foreign keys to Catalog-owned tables.
- `OrderTypeOrmConfiguration` should support `ORDER_TYPEORM_DATABASE` while
  falling back to current `TYPEORM_DATABASE` / `qrtable`.
- Keep `synchronize: true` convention for this step.
