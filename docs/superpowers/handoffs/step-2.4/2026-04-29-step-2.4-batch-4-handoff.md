## Implementation Constraints

- Redis keys must be tenant-scoped:
  - `cart:{tenantId}:{sessionId}`
  - `session:{tenantId}:{sessionId}`
- Cart snapshot stores global `cartVersion`.
- Mutations must reject stale `expectedCartVersion`.
- `ADD_ITEM` validates orderability through Catalog TCP.
- Bill lock / locked cart must prevent ordering mutations.
- Session hydration may read PostgreSQL on Redis miss, then repopulate Redis.
- Idle close must not close sessions that already have orders.
