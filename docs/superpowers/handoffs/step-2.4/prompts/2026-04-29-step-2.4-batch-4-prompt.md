## Implementation Rules

- Work on `main`.
- Do not commit.
- Do not implement submit/confirm/bill/transfer/BFF in this batch.
- Redis keys must include `tenantId`.
- Cart uses global `cartVersion` and rejects stale `expectedCartVersion`.
- `ADD_ITEM` must validate orderability through Catalog TCP.
- Locked cart must reject ordering mutations.
- Session hydration must read PostgreSQL on Redis miss and repopulate Redis.
- Idle close must not close a session that already has orders.
