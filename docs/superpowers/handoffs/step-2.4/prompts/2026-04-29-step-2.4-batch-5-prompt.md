## Implementation Rules

- Work on `main`.
- Do not commit.
- Do not implement cancellation, service requests, transfer, or BFF in this
  batch.
- Submit must be idempotent by `tenantId + sessionId + idempotencyKey`.
- Submit creates `PENDING` order and first `OPEN` bill in one Order DB
  transaction.
- Submit must not deduct stock.
- Confirm must lock order row and only allow `PENDING -> PROCESSING`.
- Confirm must call Catalog `STOCK_DEDUCT_FOR_ORDER`.
- Catalog stock failure must roll back local Order transaction.
- Create outbox row in the same transaction as confirmation.
- Publish Kafka `order.confirmed` with partition key `tenantId`.
- Do not add BFF Kafka consumer bridge.
