## Implementation Rules

- Work on `main`.
- Do not commit.
- Do not modify Customer PWA or backend code.
- Use existing `authApiClient`; do not create a second auth client.
- Preserve `Authorization` and `x-tenant-id` behavior.

## Expected Work

1. Add admin order endpoint constants.
2. Add order service methods using `authApiClient`.
3. Add React Query hooks for list/detail/confirm/cancel/table transfer method if
   grouped with order service.
4. Poll order list/detail at a modest interval such as 3-5 seconds.
5. Replace POS live orders mock source with real order list query.
6. Replace selected order lookup with real detail query where needed.
7. Wire confirm button to `POST /admin/orders/:id/confirm`.
8. Wire cancel dialog:
   - `PENDING` uses `cancel-pending`.
   - `PROCESSING` or later cancelable status uses `cancel-processing` with
     reason.
9. Invalidate list/detail queries after mutations.
10. Remove primary POS order imports from mock store/fake realtime.
11. Add tests for service methods, mutation invalidation, and cancel endpoint
    choice where feasible.
