# Step 2.7 FE-BE Realtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Triển khai realtime FE↔BE cho Customer PWA, Management POS và Management KDS theo spec Bước 2.7, không còn legacy room join, không còn batching/gom món, và có E2E đầy đủ PWA -> POS -> KDS -> PWA ready.

**Architecture:** BFF tiếp tục là boundary xác thực WebSocket và room assignment. Frontend hooks chỉ gửi identity/auth material, lắng nghe event như invalidation hint, rồi dùng TanStack Query refetch active snapshots làm nguồn sự thật. KDS giữ REST snapshot + WS invalidation hybrid; POS giữ polling dự phòng 10-15s sau khi staff realtime hoạt động.

**Tech Stack:** NestJS WebSocket Gateway, Socket.IO Client v4, TanStack Query v5, React 19, Next.js management-app, Vite customer-pwa, Jest/Nx, Playwright.

---

## Context7 Notes

- Socket.IO Client docs xác nhận `io(".../namespace", { auth: { token } })`, Manager events `reconnect`, `reconnect_error`, `reconnect_failed`, và cleanup bằng `socket.off(eventName, listener)`.
- TanStack Query docs xác nhận `invalidateQueries` mặc định refetch active matching queries và `refetchType` mặc định là `active`; `refetchInterval` là polling dự phòng khi query còn active observer.
